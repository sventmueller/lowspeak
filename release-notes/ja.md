Lowspeakが、さらに多くの場面でお使いの言語に対応しました。

- **アップデートとマイクのアクセス許可もお使いの言語で：** アップデートのウインドウと、macOSがマイクへのアクセス許可を求める画面にあるLowspeakの説明文が、Macの言語で表示されるようになりました。対象はLowspeakが対応する35言語すべてです。次回のアップデートからは、このリリースノートもお使いの言語でお届けします。
- **Homebrewでインストール：** `brew install --cask sventmueller/tap/lowspeak`。
- **よりわかりやすいメッセージ：** 後処理用のキーがない場合は、GroqとOpenAIのどちらのキーでも使えることをLowspeakがお知らせします。プロバイダがオンラインモデルの提供を終了したときは、メッセージでそのモデル名を示し、メニューへ案内します。
- **Parakeet v2** は、15秒ごとの区間の端にある単語を正確な位置に置き、各区間の最後の一瞬まで聞き取るようになりました。
