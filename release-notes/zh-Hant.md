Lowspeak 現在能在更多地方說你的語言了。

- **更新與麥克風權限請求也說你的語言：** 更新視窗，以及 macOS 詢問是否允許取用麥克風時 Lowspeak 的說明文字，都會跟隨 Mac 的語言，Lowspeak 支援的 35 種語言全都適用。從下一次更新開始，更新說明也會以你的語言呈現。
- **透過 Homebrew 安裝：** `brew install --cask sventmueller/tap/lowspeak`。
- **更清楚的訊息：** 後處理缺少密鑰時，Lowspeak 會告訴你使用 Groq 或 OpenAI 的密鑰都可以。服務提供者不再提供某個線上模型時，訊息會寫出該模型的名稱，並引導你前往選單。
- **Parakeet v2** 現在能準確定位 15 秒片段邊緣的字詞，連每個片段的最後一刻也聽得到。
