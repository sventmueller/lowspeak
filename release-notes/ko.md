Lowspeak가 이제 더 많은 곳에서 사용자의 언어로 말합니다.

- **업데이트와 마이크 권한 요청도 사용자의 언어로:** 업데이트 창과 macOS의 마이크 접근 권한 요청에 나오는 Lowspeak의 문구가 Mac의 언어를 따르며, Lowspeak가 구사하는 35개 언어 모두에 적용됩니다. 다음 업데이트부터는 이 릴리스 노트도 사용자의 언어로 제공됩니다.
- **Homebrew로 설치:** `brew install --cask sventmueller/tap/lowspeak`.
- **더 명확해진 메시지:** 후처리에 사용할 키가 없으면 Groq 또는 OpenAI 중 한 곳의 키만 있으면 된다고 Lowspeak가 알려 줍니다. 제공업체가 온라인 모델 제공을 중단하면 메시지에 해당 모델 이름과 함께 메뉴를 확인하라는 안내가 표시됩니다.
- **Parakeet v2** 모델은 이제 15초 구간의 경계에 있는 단어도 정확한 위치에 놓고, 각 구간의 마지막 순간까지 듣습니다.
