이제 Lowspeak는 받아쓰기를 잃는 일이 줄었고, 사용자의 말을 더 확실하게 받아 적습니다.

- **실패한 받아쓰기 다시 시도:** 텍스트 변환에 실패하면 Lowspeak가 녹음을 메모리에 보관합니다. 예를 들어 네트워크가 돌아왔을 때나 다른 모델을 선택한 뒤에 메뉴의 **실패한 받아쓰기 재시도**로 다시 변환할 수 있습니다.
- **텍스트는 말한 곳에:** 텍스트가 준비되기 전에 다른 앱이 앞으로 나왔다면 Lowspeak는 텍스트를 엉뚱한 앱에 붙여넣지 않고 클립보드에 남긴 뒤 알려 줍니다.
- **남은 크레딧 없음:** OpenAI 계정에 남은 크레딧이 없으면 Lowspeak는 기다리라고 하는 대신 그렇다고 알려 주며, 소용없이 다시 시도하지도 않습니다.
- **지어낸 텍스트 없음:** Whisper는 가끔 자막이 달린 동영상의 제작진 표기처럼 아무도 말하지 않은 텍스트를 무음 구간에 써 넣었습니다. 이제 Lowspeak는 이런 텍스트를 제외합니다.
- **사용자의 어휘와 Whisper:** Whisper가 앞 문장과 같은 말로 시작하는 문장을 더 이상 빠뜨리지 않습니다.
- **사용자의 어휘와 Parakeet:** Parakeet이 아주 비슷하게 쓴 곳에서는 이제 용어를 사용자가 입력한 표기대로 씁니다. 예를 들어 “Träfig” 대신 Traefik으로 씁니다.
