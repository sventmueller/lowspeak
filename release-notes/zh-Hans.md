Lowspeak 现在能在更多地方说你的语言了。

- **更新和麦克风权限请求也说你的语言：** 更新窗口，以及 macOS 请求访问麦克风时 Lowspeak 的说明文字，都会跟随 Mac 的语言，Lowspeak 支持的 35 种语言全都适用。从下一次更新起，更新说明也会使用你的语言。
- **通过 Homebrew 安装：** `brew install --cask sventmueller/tap/lowspeak`。
- **更清晰的提示信息：** 后处理缺少密钥时，Lowspeak 会告诉你用 Groq 或 OpenAI 的密钥都可以。服务提供商不再提供某个在线模型时，提示会写明该模型的名称，并引导你前往菜单。
- **Parakeet v2** 现在能准确定位 15 秒片段边缘处的词，连每个片段的最后一刻也能听到。
