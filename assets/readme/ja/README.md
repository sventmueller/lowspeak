# Lowspeak

**fnを押したまま話して、離すだけ。言葉はもう入力されています。**

Lowspeakはメニューバーに常駐し、fnキーを押している間だけ耳を傾けます。書きたいことを話して離せば、メール、チャット、コードエディタ、ターミナルなど、いま使っているAppにテキストが入力されます。

ブラウザエンジンを使わず、RustでAppKit上に作られた本物のMacアプリケーションです。すぐに起動し、作業の邪魔をしません。話している最中に接続まで開いておくので、オンラインの文字起こしはキーを離してから約0.4秒で届きます。

音声認識モデルは12種類から選べます。自分のGroqキーを使えば、Groqの1日の利用枠内ならオンラインの文字起こしに料金はかかりません。難しい録音は、OpenAIのGPT Transcribeが引き受けます。Lowspeakはこれらと直接やり取りします。アカウントは不要で、間に独自のサーバーを挟むこともありません。

あるいは、すべてをMacの中だけで完結させることもできます。WhisperとNVIDIA Parakeetはオフラインで動作するので、声がMacの外に出ることはありません。Parakeetは40秒の音声を約3分の1秒でテキストにします。オンラインで使っているときも、ネットワークが切れればインストール済みのローカルモデルが代わりを務めるので、音声入力が失われることはありません。

Lowspeakは35の言語に対応しています。よく使う名前や用語を覚え、つなぎ言葉を取り除いて文法を整えることもできます。最近の10件の音声入力はメニューに残るので、必要になったらもう一度使えます。

## 主な機能

- **骨の髄までネイティブ。** AppKitのメニューを備えた本物のメニューバー項目、標準のアラートと通知。Electronも、ウインドウも、Dockのアイコンもありません。
- **用途に合ったモデル。** Macのメモリを使わずに速さを求めるならGroq、最高の結果ならOpenAIのGPT Transcribe、オフラインで作業し、声を外に出したくないならMac上のWhisperまたはNVIDIA Parakeet。ワンクリックで切り替えられます。
- **プライベート。** アカウントもテレメトリもありません。音声は選んだプロバイダにだけ送られ、ローカルモードではどこにも送られません。
- **音声入力を失いません。** ネットワークやオンラインサービスに障害が起きると、インストール済みのローカルモデルが同じ録音をMac上で文字起こしします。
- **あなたの言語で。** 音声入力は数十の言語で使え、メニュー、ダイアログ、通知は35の言語に対応しています。
- **言葉を正しい表記で。** 名前や専門用語の用語集が、OpenAI、Groq、Whisper、後処理の手がかりになります。
- **必要ならきれいなテキストに。** オプションの後処理は、つなぎ言葉を取り除き、文法を直し、言い直したときは訂正後の内容だけを残します。音声入力先のAppの種類に合わせてテキストを整形することもできます。
- **クリップボードはあなたのもの。** Lowspeakはクリップボード経由でペーストし、すぐあとに元の内容を戻します。最近の10件の音声入力はメニューに残り、もう一度コピーできます。
- **fnを押したまま話して、離すだけ。** テキストは、前面にあるAppのカーソル位置に入力されます。メール、チャット、エディタ、ターミナル、ブラウザのどこでも使えます。切り替えるウインドウも、クリックするボタンもありません。
- **長い文章はロックして。** fnを押したままShiftを押すか、fnを2回押すと、キーを押していなくても録音が最長5分間続きます。fnかShiftを1回押すと終了します。
- **話し続けられます。** 前の音声入力がまだ文字起こし中でも、次の音声入力を始められます。テキストは話した順に届きます。

## 動作環境

- macOS 14 Sonoma以降。Lowspeakの開発とテストはmacOS 27で行っています。
- Apple SiliconまたはIntelプロセッサ搭載のMac。ローカルの文字起こしはApple Silicon向けに作られており、WhisperはGPUで、ParakeetはNeural Engineで動作します。Intel搭載のMacではどちらもプロセッサで動作するため、ずっと遅くなります。[Intel搭載のMac](#intel搭載のmac)を参照してください。
- Appに約17 MB、さらにダウンロードするローカルモデルごとに75 MB～3 GB。
- オンラインで文字起こしするには、[OpenAI](https://platform.openai.com/api-keys)または[Groq](https://console.groq.com/keys)のAPIキーが必要です。OpenAIでは文字起こしした分の料金がかかります。Groqの無料プランなら、1日の上限内で料金はかかりません。上限はGroqのコンソールに表示されます。ローカルの文字起こしにはアカウントは不要です。

## インストール

**ディスクイメージから。** [`Lowspeak.dmg`](https://github.com/sventmueller/lowspeak/releases/latest/download/Lowspeak.dmg)をダウンロードして開き、Lowspeakをアプリケーションフォルダにドラッグしてください。イメージはDeveloper IDで署名され、Appleによって公証されているため、警告なしで開きます。

**Homebrewで。** Caskは専用のtapにあります。

```sh
brew install --cask sventmueller/tap/lowspeak
```

`brew uninstall --zap --cask lowspeak`では、Lowspeakの設定、モデル、ログ、キャッシュも削除されます。APIキーはログインキーチェーンに残ります。

**アップデート。** ディスクイメージまたはHomebrewで入れたLowspeakは、[Sparkle](https://sparkle-project.org)によって自動的に最新の状態に保たれます。2回目の起動時に、1日1回、自動でアップデートを確認してよいかをたずねます。メニューの**アップデートを確認…** はすぐに確認します。あとから選択を変えるには、その下にある**アップデートを自動的に確認**と**アップデートを自動的にダウンロードしてインストール**を使います。ほかのAppで作業している間に確認で新しいバージョンが見つかると、メニューバーのリングに点が付き、**アップデートを確認…** でアップデートが前面に表示されます。Lowspeakは、開発者の署名があるアップデートだけをインストールします。設定、キー、モデルはそのまま残ります。Homebrewで入れたコピーは、`brew upgrade --cask lowspeak`でもアップデートできます。バージョン1.0.0にはアップデータがありません。一度だけ、[リリースページ](https://github.com/sventmueller/lowspeak/releases)から新しいバージョンを上書きしてインストールしてください。自分でビルドしたものにもアップデータはありません。

**ソースから。** 前提条件は[Build & Deploy](../../../docs/development.md#build--deploy)を参照してください。そのあとは次のとおりです。

```sh
make deploy
```

これでLowspeakがビルドされ、アプリケーションフォルダ内のコピーが置き換えられて、起動します。

メニューの**ログイン時に開く**をオンにすると、macOS自体のログイン項目を通じて、Macの起動とともにLowspeakが起動します。同時に実行できるのは1つだけで、2つ目はすぐに終了します。

## はじめに

### アクセス許可

初めて起動したとき、Lowspeakは3つのアクセス許可を求めます。

- **アクセシビリティ**（システム設定 › プライバシーとセキュリティ › アクセシビリティ。macOS 27ではこのリストの名前は「デバイスの制御とデータへのアクセス」です）。Lowspeakがfnキーを検知し、⌘Vでペーストするために必要です。macOSがリストを開くよう提案するので、Lowspeakのスイッチをオンにしてください。Lowspeak自身のメッセージでは、お使いのmacOSでの表示どおりの名前でこのリストを示します。
- **マイク。** 一度だけたずねられます。許可しないと、Lowspeakは何も録音しません。
- **通知。** 無音のマイクや文字起こしの失敗など、ほかの方法では気づかない問題を知らせるために使います。

### 文字起こしの方法を選ぶ

少なくとも1つの方法を設定してください。メニューでいつでも切り替えられます。

- **オンライン：** **APIキーを設定…** を選び、OpenAIのキー（`sk-`で始まります）またはGroqのキー（`gsk_`）をペーストします。Lowspeakはキーからプロバイダを判別します。そのあと、**OpenAI** または **Groq** の下でモデルを選びます。
- **Mac上で：** **モデルを管理** › **Parakeet Ultraをダウンロード** またはWhisperモデルを選び、**ローカル**の下でそのモデルを選びます。

[自分に合ったモデル](#自分に合ったモデル)が選ぶ手助けになります。そのあと、fnを押したまま何か話して、離してください。

### メニュー

メニューバーのリングをクリックします。

| 項目 | 機能 |
|---|---|
| **最近の音声入力** | 最近の10件のテキスト。クリックすると、もう一度クリップボードにコピーされます |
| **ローカル** | Mac上のモデル。WhisperとParakeetに分かれていて、ダウンロードしていないものは淡色表示されます |
| **OpenAI**、**Groq** | オンラインのモデル。キーがない場合は淡色表示され、メニューに **APIキーを設定…** が表示されます |
| **言語** | 音声入力する言語、または **自動検出**。メニューの言語もこれに従います |
| **後処理** | **オフ**、**クリーンアップ**、**整形**。[後処理](#後処理)を参照してください |
| **用語集…** | 正確に表記したい名前や用語。入力した数がメニューに表示されます |
| **マイク** | **システムのデフォルト**または固定のマイク、および **準備ができたらサウンドを再生** |
| **モデルを管理** | ローカルモデルのダウンロードと削除。進捗も表示されます |
| **APIキーを設定…** / **APIキーを更新…** | キーの追加、置き換え、削除 |
| **ログイン時に開く** | Macの起動とともにLowspeakを起動します。オンのときはチェックマークが付きます |
| **アップデートを確認…** | 新しいバージョンを今すぐ確認します。その下の2つの項目で、Lowspeakが1日1回確認するか、たずねずにアップデートをインストールするかを決めます。ディスクイメージから入れたAppにのみあります |
| **ヘルプ** | **クイックリファレンス**、**問題を報告…**、**機能を提案…**、**GitHubのLowspeak** |
| **Lowspeakについて** | バージョン、著作権、プロジェクトページ、ライセンス |
| **Lowspeakを終了** | メニューが開いているときは⌘Q |

**ローカル**、**OpenAI**、**Groq**の下のチェックマークは、使用中のモデルを示します。アイコンは、Lowspeakがいま何をしているかを示します。

| アイコン | 意味 |
|---|---|
| 点の入ったリング | 準備完了 |
| 塗りつぶした円 | fnを押している間の録音中 |
| 角の丸い四角形 | ロックされた録音中。次にfnかShiftを押すと終了します |
| 点滅するリング | 文字起こし中 |
| 右上に点の入ったリング | 新しいバージョンが待機中。**アップデートを確認…** を参照してください |
| ↓ 42% | モデルをダウンロード中 |

Lowspeakには設定ウインドウがありません。すべてがこのメニューにあり、選んだ内容はすべて記憶されます。

### クイックリファレンス

**ヘルプ › クイックリファレンス**を選ぶと、fnのジェスチャが小さなウインドウにお使いの言語で表示されます。キーボード設定を開くボタンもあります。**問題を報告…** はLowspeakとmacOSのバージョンが入力されたGitHubのフォームを開き、**機能を提案…** はアイデアのためのディスカッションを、**GitHubのLowspeak** はプロジェクトページを開きます。

## 音声入力

### 押したまま話す

fnを押したまま話して、離します。マイクが音を届け始めた瞬間に録音アイコンが表示されます。話し始めるのはそれからにしてください。それより前に話した内容は録音されません。fnを離すと録音が終わり、少しするとテキストが入力されます。

fnを短くタップしても何も起こらないので、fnはほかの用途にもそのまま使えます。空のままの録音や0.3秒未満の録音は破棄されます。

### Shiftまたは2回押しでロックする

長い文章では、キーを押していなくても続くよう録音をロックします。方法は3つあります。

- **fnを押したままShift。** いつもどおりfnで始め、録音中にShiftを押します。録音がロックされ、fnを離してもかまいません。それまでに話した内容は失われず、録音はそのまま続きます。
- **Shiftのあとにfn。** Shiftを押したままfnを押すと、ロックされた状態で録音が始まります。
- **fnを2回。** fnを短く（0.3秒未満）タップし、0.4秒以内にもう一度押します。録音は1回目に押したときから始まります。

アイコンが角の丸い四角形に変わります。止めるには **fn** か **Shift** を1回押します。テキストはいつもどおり入力されます。🌐キーで絵文字と記号を開くように設定している場合は、Shiftで止めてください。fnを短く押すとビューアが開いてしまいます。

録音は、fnを押している間は2分後に、ロック中は5分後に自動的に止まり、いつもどおり文字起こしされます。

### テキストの入力先

Lowspeakは、話し終えたときに前面にあったAppのカーソル位置に、クリップボードと⌘Vを使ってテキストをペーストします。それまでクリップボードにあったものはすべて保存しておき、Appがテキストを読み取ってから0.5秒後に、読み取らない場合は10秒後に元に戻します。ただし、その間にほかのAppがクリップボードを変更した場合は戻しません。テキストには一時的なデータであることを示すマークが付くため、このマークに対応したクリップボード履歴Appには記録されません。

前の音声入力がまだ文字起こし中でも、次の音声入力を始められます。テキストは話した順にペーストされ、録音中やShiftを押している間にはペーストされないので、次の文の途中にペーストが割り込むことはありません。

アクセシビリティの許可がない場合や、シミュレートした⌘Vを送れない場合は、テキストはクリップボードに残り、通知でそのことが知らされます。⌘Vで自分でペーストしてください。

### 最近の音声入力

メニューの**最近の音声入力**には、最近の10件のテキストが新しい順に、それぞれ1行に短縮して表示されます。ポインタを重ねるとテキスト全体が表示されます。クリックするとクリップボードにコピーされるので、テキストが違う場所に入力されたときや、同じテキストが2回必要なときに使えます。リストはメモリ上にしかなく、Lowspeakを終了すると空になります。

## 文字起こし

### 自分に合ったモデル

| 目的 | 選ぶもの | 理由 |
|---|---|---|
| **Macを使わずに速さを** | **Groq › Whisper Large V3 Turbo** | 最も速いオンラインの選択肢。何もダウンロードせず、Macのメモリとディスク容量はそのままです |
| **最高の結果** | **OpenAI › GPT Transcribe**（デフォルト） | Lowspeakが提供するモデルの中で最も正確。用語集をキーワードとして受け取ります |
| **オフラインでプライベートに** | ヨーロッパの言語なら **ローカル › Parakeet Ultra**、それ以外の言語なら **ローカル › Whisper Large v3 Turbo** | ネットワークなしで動作し、声がMacの外に出ることはありません。Parakeetは全モデルの中で最速です |
| **アカウントなし、費用なし** | どの **ローカル** モデルでも | Mac上で動作し、料金は一切かかりません |
| **オンラインなのに無料** | 無料プランの **Groq** | 支払い方法を登録していないGroqアカウント。Groqの1日の上限内なら、文字起こしに料金はかかりません |
| **信頼性と速さの両立** | オンラインのモデルに加え、Parakeet UltraまたはWhisperモデルをインストール | オンラインサービスが失敗したときにローカルモデルが代わりを務めます |
| **Intel搭載のMac** | **Groq** または **OpenAI** | Intel搭載のMacではローカルモデルがプロセッサで動作します。[Intel搭載のMac](#intel搭載のmac)を参照してください |

ローカルモデルは、ダウンロードサイズと同じだけのディスク容量を使い、選択している間はほぼ同じ量のメモリも使います。すぐに音声入力を始められるよう、Lowspeakはモデルを読み込んだままにしておきます。メモリが8 GBのMacでは、大きなWhisperモデルよりもParakeet Ultraかオンラインのモデルを選んでください。

### オンライン：OpenAIとGroq

| モデル | プロバイダ | 備考 |
|---|---|---|
| **GPT Transcribe**（デフォルト） | OpenAI | 最も正確。用語集をキーワードとして受け取ります |
| **Whisper** | OpenAI | オリジナルのWhisperモデル |
| **Whisper Large V3** | Groq | 非常に高速 |
| **Whisper Large V3 Turbo** | Groq | オンラインで最速 |

録音はアップロードの前にAACに圧縮され、音声1秒あたり約6 KBになるので、遅い回線でも音声入力できます。fnを押している間に、Lowspeakはもうプロバイダへの接続を開いておくので、離した瞬間にアップロードが始まります。

### Mac上で：WhisperとParakeet

| モデル | サイズ | 実行場所 | 言語 |
|---|---|---|---|
| **Parakeet Ultra** | 約630 MB | Neural Engine | ヨーロッパの25言語 |
| **Parakeet v2** | 約600 MB | Neural Engine | 英語 |
| **Whisper Large v3 Turbo** | 約1.6 GB | GPU（Metal） | 約99 |
| **Whisper Large v3** | 約3 GB | GPU（Metal） | 約99 |
| **Whisper Medium** | 約1.5 GB | GPU（Metal） | 約99 |
| **Whisper Small** | 約470 MB | GPU（Metal） | 約99 |
| **Whisper Base** | 約150 MB | GPU（Metal） | 約99 |
| **Whisper Tiny** | 約75 MB | GPU（Metal） | 約99 |

**モデルを管理**でモデルのダウンロードと削除ができます。ダウンロード中はメニューバーに進捗が表示され、Lowspeakを終了するとダウンロードは中止されます。モデルを初めて使うときは、お使いのMac向けの準備が行われます。Parakeet Ultraで約10秒、Whisperで最大30秒です。それ以降は1秒もかからずに読み込まれます。選んでいたモデルが削除された場合、Lowspeakはインストール済みのほかのモデルに切り替えます。

**Parakeet**は最速の選択肢で、40秒の音声を約0.3秒で文字起こしします。Lowspeakは[FluidAudio](https://github.com/FluidInference/FluidAudio)と同じモデルとデコード方式でParakeetを実行し、モデルをFluidAudioのフォルダ（`~/Library/Application Support/FluidAudio/Models`）に保存するので、FluidAudioを使って作られたAppとモデルを共有できます。15秒を超える録音は、重なり合う区間に分けて文字起こしされ、つなぎ目で単語が失われないように結合されます。**Whisper**はより多くの言語を理解し、用語集を読み取ります。大きなモデルが最も正確で、小さなモデルは英語以外ではかなり精度が落ちます。Whisperモデルは`~/Library/Application Support/Lowspeak/Models`に保存されます。

### オンラインサービスが失敗したとき

ネットワークがダウンしている、プロバイダに問題がある、キーが間違っているなどの理由でオンラインの文字起こしに失敗すると、インストール済みのローカルモデルが同じ録音を文字起こしします。使われるのは **ローカル** で選んだモデル、それがなければParakeet Ultra、次にWhisper Large v3 Turbo、Large v3、小さいWhisperモデルの順で、Parakeet v2は最後です。通知は一度だけ届き、その後オンラインの音声入力が一度成功するまで、再び届くことはありません。

フォールバック先のローカルモデルがある場合、Lowspeakはオンラインのリクエストに20秒を与えます。ない場合は、それぞれ最長1分で3回試します。オンラインモードでは、Lowspeakは起動時にフォールバック用のParakeetモデルを一度準備しておくので、最初のフォールバックでその準備を待つことはありません。

### 録音の前処理

Lowspeakはマイク本来のサンプリングレートで録音し、録音を止めた時点で、モデルが必要とする16 kHzに変換します。文字起こしの前に、80 Hz未満の低いノイズを取り除き、最初と最後の無音を切り詰め、音量を均一にするので、小さな声の人も大きな声の人も同じように扱われます。音声を含まない録音は送信されません。ローカルモードでは、Parakeetはまず手を加えていない録音を受け取り、それでテキストが得られなかった場合にだけ前処理した録音を受け取ります。

### モデルごとの言語

**言語**で選んだ言語は、オンラインのモデルとWhisperに渡されます。**自動検出**では、モデルが自分で言語を判断します。

| モデル | 音声入力できる言語 |
|---|---|
| GPT Transcribe、Whisper（OpenAI、Groq、Mac上） | 約99。メニューの35言語すべてを含みます |
| Parakeet Ultra | ブルガリア語、クロアチア語、チェコ語、デンマーク語、オランダ語、英語、エストニア語、フィンランド語、フランス語、ドイツ語、ギリシャ語、ハンガリー語、イタリア語、ラトビア語、リトアニア語、マルタ語、ポーランド語、ポルトガル語、ルーマニア語、ロシア語、スロバキア語、スロベニア語、スペイン語、スウェーデン語、ウクライナ語 |
| Parakeet v2 | 英語 |

Parakeetは言語を自分で判断し、メニューでの選択を無視します。**繁體中文**を選ぶと、GPT Transcribeは繁体字で書きます。Whisperは中国語を簡体字と繁体字のどちらでも書くことがあり、ポルトガル語も地域による違いを区別せずに書きます。

### Intel搭載のMac

Lowspeakはユニバーサルアプリケーションで、macOS 14を搭載したIntel搭載のMacでも動作します。オンラインの機能はすべて同じように使えます。ただし、ローカルモデルはそこでは本来想定しているハードウェアを使えません。WhisperはGPUではなくプロセッサで、ParakeetはNeural Engineではなくプロセッサで動作します。どちらも動作はしますが、Apple Siliconの何倍も時間がかかり、大きなWhisperモデルは音声入力には遅すぎます。Intel搭載のMacでは、オンラインで文字起こしし、Whisper SmallかParakeet Ultraを[フォールバック](#オンラインサービスが失敗したとき)として用意しておいてください。

## 用語集

**用語集…** には、Lowspeakに正確に表記してほしい名前や用語を、カンマで区切って入力します。製品名、同僚の名前、専門用語などです。最大100語、1語あたり最大60文字で、`<`と`>`は削除されます。

- **GPT Transcribe**はキーワードとして受け取ります。
- **Whisper**（OpenAI、Groq、Mac上）は、録音の前に置かれるヒントとして、最大500文字まで読み取ります。
- **後処理**には、書かれたとおりに正確に表記するよう指示されます。
- **Parakeet**は使いません。

## 後処理

文字起こしのあと、言語モデルがテキストを手直しできます。**後処理**で選びます。

- **オフ**（デフォルト）— 文字起こししたままのテキスト。
- **クリーンアップ** — 「えーと」「なんか」「要するに」のようなつなぎ言葉を取り除き、文法と句読点を直し、言い直したときは訂正後の内容だけを残します。何も付け加えず、意味も変えません。
- **整形** — クリーンアップと同じ処理に加えて、音声入力先のAppに合わせてテキストを整えます。コードエディタではコード風の用語に、ターミナルではコマンドラインに、チャットAppではくだけた調子に、メールではビジネス向けの調子にします。

後処理には、Groqのキーがあれば、Groq（`openai/gpt-oss-120b`）を、なければOpenAI（`gpt-4o-mini`）を使います。ローカルで文字起こしする場合も同じです。**言語**で言語を選んでいる場合は、その言語を保ちます。8秒より長くかかった場合、失敗した場合、または返ってきた答えが途中で切れていたり、話した内容よりはるかに長かったりした場合、Lowspeakは処理していないテキストをペーストします。プロバイダがリクエストを拒否した場合やキーが設定されていない場合は、一度だけ通知でお知らせします。

## マイク

**マイク**で、固定のマイクか **システムのデフォルト** を選びます。Lowspeakはデバイスを記憶し、そのデバイスが接続されていない間は、メニューに **(未接続)** と表示して、システムのデフォルトで録音します。

マイクは音声入力している間だけオンになります。準備にかかる時間は、内蔵マイクで約0.07秒、Studio Displayで約0.5秒、AirPodsでは、まずヘッドセットモードに切り替わるため1～2秒です。音が届くと録音アイコンが表示されます。**準備ができたらサウンドを再生** をオンにすると、その瞬間に短いサウンドが鳴ります。一部のスピーカーではサウンド自体が0.5秒遅れて鳴るため、デフォルトではオフです。

マイクから5秒間無音しか届かない場合は、Lowspeakがお知らせします。ほかのデバイスがAirPodsのマイクを使っているときには、AirPodsがそうなります。

## APIキー

**APIキーを設定…** はキーを求め、その先頭からプロバイダを判別します。OpenAIは`sk-`、Groqは`gsk_`です。ほかの形式のキーは、説明とともに拒否されます。キーはプロバイダごとに1つ入力します。両方のキーがあれば、すべてのオンラインモデルを使えます。**APIキーを更新…** はキーを置き換えます。**すべてのキーを削除** でキーを削除することもできます。

キーは、ログインキーチェーンに`com.lowspeak.app`という名前で保存されます。以前のバージョンのキーファイル（`~/Library/Application Support/Lowspeak/.api-key`）は、次回の起動時にキーチェーンへ移され、すべてのキーをキーチェーンから読み出せることを確かめたうえで削除されます。

## 通知

Lowspeakはバックグラウンドで動作するため、問題は通知で知らせます。

| 通知 | 発生した状況 |
|---|---|
| **録音に失敗しました** | マイクへのアクセスがない、マイクが接続されていない、またはマイクを開始できなかった |
| **マイクが無音です** | 5秒間の無音。[マイク](#マイク)を参照してください |
| **アクセシビリティの許可が必要です** | テキストはクリップボードにあります。自動でペーストするにはアクセシビリティを許可してください |
| **ペーストに失敗しました** | テキストはクリップボードにあります。⌘Vでペーストしてください |
| **文字起こしに失敗しました** | 理由付き：キーがない、キーが拒否された、リクエストの上限、サーバまたはネットワークのエラー、ローカルモデルがない |
| **このMacで文字起こししました** | オンラインサービスが失敗し、ローカルモデルが代わりに処理しました |
| **後処理に失敗しました** | プロバイダが後処理を拒否しているか、キーが設定されていません。テキストは後処理なしでペーストされました |
| **APIキーがありません** | プロバイダのキーがないオンラインモデルを選びました |
| **ダウンロードに失敗しました**、**削除に失敗しました**、**削除できません** | ローカルモデルの管理がうまくいかなかったか、ほかの処理がまだ実行中でした |
| **ログイン項目のエラー**、**APIキーのエラー** | macOSまたはキーチェーンが変更を拒否しました |

通知に音声入力したテキストが含まれることはありません。オンラインサービスの障害と、後処理を拒否するプロバイダについては、音声入力のたびではなく、再び動作するまでの間に一度だけ知らせます。

## 外観とアクセシビリティ

- **メニューバーのアイコン**はテンプレートイメージで、明るい、暗い、または色付きのメニューバーに合わせて表示されます。
- **VoiceOver**はアイコンを「Lowspeak」と読み上げます。メニュー、アラート、通知は標準のmacOSコントロールです。
- **キーを押し続ける必要はありません。** Shiftかfnの2回押しで録音をロックすれば、次に押したときに終了します。

既知の不足点は[ACCESSIBILITY.md](../../../ACCESSIBILITY.md)に記載しています。VoiceOverは録音の開始を読み上げません。また、LowspeakはまだVoiceOverやスイッチコントロールでの確認を受けていません。

| 操作 | キー |

## プライバシーとセキュリティ

Lowspeakは、fnを押している間に話した内容を聞き、どのAppにも入力でき、APIキーを保管します。そのため、それらを使ってすることは最小限にとどめています。

- **声が届くのは1か所だけ。** オンラインモードでは、圧縮した録音が、用語集と一緒に、選んだプロバイダ（OpenAIまたはGroq）に送られます。ローカルモードでは、何もMacの外に出ません。オンラインのリクエストが失敗した場合は、ローカルモデルが同じ録音をMac上で文字起こしします。
- **後処理**をオンにすると、文字起こししたテキストと用語集がGroqまたはOpenAIに送られます。整形モードでは、音声入力先のAppの種類（コードエディタ、ターミナル、チャット、メール）も追加されます。Appの名前は送られません。
- **テレメトリなし、アカウントなし。** 文字起こしと後処理以外でLowspeakがネットワークに接続するのは、オンラインモードまたは後処理がオンのときに、fnを押している間にプロバイダへの接続を開くとき、求められたモデルをHugging FaceからHTTPSでダウンロードするとき、そして許可した場合に1日1回GitHubで新しいバージョンを確認するときだけです。ダウンロードするのは固定されたバージョンで、すべてのファイルをチェックサムと照合します。バージョン確認のリクエストに含まれるのはLowspeakのバージョンだけです。**ヘルプ › 問題を報告…** を選ぶと、ブラウザでGitHubのフォームが開きます。そのアドレスに含まれるのはLowspeakのバージョンとmacOSのバージョンだけで、音声入力した内容は含まれません。
- **APIキー**はログインキーチェーンに保存されます。キーはそれぞれのプロバイダにだけ送られ、ログに何かを書き込む前にエラーメッセージから取り除かれます。
- **音声入力したテキストは保存されません。** 最近の10件の音声入力は、**最近の音声入力**のためにメモリ上に残り、Lowspeakを終了すると消えます。ログファイルに記録されるのは長さと所要時間だけで、テキストは決して記録されません。
- **クリップボード**は、ペーストする前に保存され、Appがテキストを読み取ったあとに元に戻されます。ただし、その間にほかのAppが変更した場合は戻しません。音声入力したテキストには一時的なデータであることを示すマークが付くため、このマークに対応したクリップボード履歴Appには記録されません。
- **コード署名**にはHardened Runtimeを使っています。Appが求めるのは、マイク、アクセシビリティ、通知、ネットワークだけです。アップデートには開発者の署名が必要で、署名がなければSparkleが拒否します。

脆弱性を報告するには、[セキュリティポリシー](../../../SECURITY.md)に従ってください。

## 速度

Apple Siliconでの測定値です。

- **Parakeet Ultra**は40秒の音声を約0.3秒で文字起こしします。
- **オンライン：** 間を置いたあとの最初のリクエストは、Groqで約0.4秒です。まだ話している間にLowspeakが接続を開いておくためです。以降のリクエストはその接続を再利用し、プロバイダが対応していればHTTP/3を使います。
- **アップロードサイズ：** 48 kbit/sのAACで、音声1秒あたり約6 KB。
- **マイクの準備：** 内蔵マイクで約0.07秒、Studio Displayで約0.5秒、AirPodsで1～2秒。

## 既知の制限

- **Intel搭載のMacのローカルモデル**はプロセッサで動作するため、ずっと遅くなります。そこではオンラインの文字起こしのほうが適しています。
- **マイクの準備ができる前に話した内容は失われます。** 特にAirPodsでは、録音アイコンが表示されるまで待ってください。
- **fnキーがほかに取られることがあります。** macOSの🌐キーの設定、Warp、macOSの音声入力が先にfnを使うと、Lowspeakはfnを検知できません。[トラブルシューティング](#トラブルシューティング)を参照してください。
- **Parakeet**は用語集と言語の選択を無視し、ヨーロッパの言語しか認識しません。
- **字体と地域による違い：** 繁体字で書くよう指示できるのはGPT Transcribeだけです。ブラジルではなくヨーロッパのポルトガル語で書くよう指示できるモデルはありません。
- **時間制限：** fnを押している間は2分、ロック中は5分。
- **マイクモード：** コントロールセンターはLowspeakに対しても「声を分離」と「ワイドスペクトル」を表示し、有効と報告しますが、Lowspeakは音声処理なしで録音するため、この選択は効果がありません。
- **最近の音声入力**はメモリ上にしかなく、終了すると消えます。
- **仕様として：** 設定ウインドウなし、Dockのアイコンなし、App Storeでは提供しません。

## トラブルシューティング

**fnを押し続けても何も起こりません。** 次の3点を確認してください。**システム設定 › プライバシーとセキュリティ › アクセシビリティ**（macOS 27では **デバイスの制御とデータへのアクセス**）でLowspeakが許可されていること、**システム設定 › キーボード › 🌐キーを押して** が **何もしない** に設定されていること、ほかのAppがfnを使っていないこと。Warpはデフォルトでfnを使います。`defaults write dev.warp.Warp-Stable VoiceInputToggleKey '""'`でオフにして、Warpを再起動してください。macOSの音声入力も、fnで開始するよう設定されていることがあります。

**アップデート後、Lowspeakがfnに反応しなくなりました。** macOSは、アクセシビリティの許可をAppの署名に結び付けています。たとえば自分でビルドしたものからダウンロードしたAppに替えたときなど、署名が変わった場合は、アクセシビリティのリスト（macOS 27では「デバイスの制御とデータへのアクセス」）からLowspeakを削除して、もう一度追加してください。

**最初の言葉が抜けます。** 録音アイコンが表示されてから話し始めてください。AirPodsでは、マイクの準備に1～2秒かかります。**マイク**で内蔵マイクやUSBマイクを選べば、ほぼすぐに準備ができます。

**「マイクが無音です」。** マイクから5秒間音が届きませんでした。AirPodsの場合、ほかのデバイスがそのマイクを使っている可能性があります。内蔵マイクに切り替えるか、AirPodsを接続し直してください。MacBookの蓋を閉じた場合も、内蔵マイクは消音されます。

**音声入力の結果が空になります。** 入力音量が低すぎる可能性があります。Teams、Zoom、MeetなどのAppは通話中に入力音量を変更し、macOSはその音量をデバイスごとに保持します。**システム設定 › サウンド › 入力** で上げてください。

**テキストが違う場所に入力されました。** メニューの **最近の音声入力** から、もう一度クリップボードにコピーできます。

**「APIキーがありません」。** メニューで **APIキーを設定…** を選ぶか、ローカルモデルに切り替えてください。

**最初のローカルの文字起こしに時間がかかります。** 各モデルは、初めて使うときにお使いのMac向けに準備されます。それ以降は1秒もかからずに読み込まれます。

**起動直後にLowspeakが終了します。** 別のLowspeakがすでに実行中です。先にそちらを終了してください。

**通知が表示されません。** **システム設定 › 通知 › Lowspeak** で許可してください。

**そのほか。** `~/Library/Application Support/Lowspeak/`にあるログ（`appstate.log`、`audio.log`、`hotkey.log`、`crash.log`）に、何が起きたかが記録されています。音声入力したテキストは含まれません。関連する行を[問題の報告](https://github.com/sventmueller/lowspeak/issues/new/choose)に添付してください。
