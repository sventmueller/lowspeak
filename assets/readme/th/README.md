# Lowspeak

**กด fn ค้างไว้ พูด แล้วปล่อย คำพูดของคุณก็ไปอยู่ตรงนั้นแล้ว**

Lowspeak อยู่ในแถบเมนูของคุณ และจะฟังเฉพาะตอนที่คุณกดปุ่ม fn ค้างไว้เท่านั้น พูดสิ่งที่อยากเขียน ปล่อยปุ่ม แล้วข้อความจะปรากฏในแอปที่คุณใช้อยู่ ไม่ว่าจะเป็นอีเมล แชท ตัวแก้ไขโค้ด หรือเทอร์มินัล

นี่คือแอป Mac ตัวจริง เขียนด้วย Rust บน AppKit โดยไม่มีเอนจินเบราว์เซอร์อยู่เบื้องหลัง เปิดขึ้นมาได้ทันทีและไม่เกะกะการทำงานของคุณ แถมยังเปิดการเชื่อมต่อไว้ตั้งแต่คุณยังพูดอยู่ ข้อความจากการถอดเสียงออนไลน์จึงมาถึงในราว 0.4 วินาทีหลังจากคุณปล่อยปุ่ม

เลือกได้จากโมเดลถอดเสียง 12 โมเดล ถ้าใช้คีย์ Groq ของคุณเอง การถอดเสียงออนไลน์จะไม่มีค่าใช้จ่ายภายในโควตารายวันของ Groq ส่วนการบันทึกที่ถอดยาก ก็มี GPT Transcribe ของ OpenAI คอยจัดการให้ Lowspeak ติดต่อกับบริการเหล่านี้โดยตรง ไม่ต้องมีบัญชี และไม่มีเซิร์ฟเวอร์ของตัวเองคั่นกลาง

หรือจะเก็บทุกอย่างไว้บน Mac ของคุณก็ได้ Whisper และ NVIDIA Parakeet ทำงานแบบออฟไลน์ เสียงของคุณจึงไม่ออกจากเครื่องเลย และ Parakeet เปลี่ยนเสียงพูด 40 วินาทีเป็นข้อความได้ในราวหนึ่งในสามวินาที หากคุณทำงานแบบออนไลน์ โมเดลในเครื่องที่ติดตั้งไว้จะเข้ามาทำงานแทนเมื่อเครือข่ายหลุด การป้อนตามคำบอกจึงไม่สูญหาย

Lowspeak พูดได้ 35 ภาษา เรียนรู้ชื่อและศัพท์ที่คุณใช้ ตัดคำติดปากและเกลาไวยากรณ์ให้ได้ และเก็บการป้อนตามคำบอกสิบรายการล่าสุดไว้ในเมนู เผื่อคุณต้องใช้อีกครั้ง

## ภาพรวมความสามารถ

- **เป็นเนทีฟอย่างแท้จริง** รายการในแถบเมนูจริงพร้อมเมนู AppKit หน้าต่างเตือนและการแจ้งเตือนมาตรฐาน ไม่มี Electron ไม่มีหน้าต่าง ไม่มีไอคอนใน Dock
- **โมเดลที่เหมาะกับงาน** Groq สำหรับความเร็วโดยไม่ใช้หน่วยความจำของ Mac, GPT Transcribe ของ OpenAI สำหรับผลลัพธ์ที่ดีที่สุด, Whisper หรือ NVIDIA Parakeet บน Mac ของคุณสำหรับการทำงานออฟไลน์และเก็บเสียงของคุณไว้เป็นส่วนตัว สลับได้ในคลิกเดียว
- **เป็นส่วนตัว** ไม่มีบัญชี ไม่มีการเก็บข้อมูลการใช้งาน เสียงจะไปยังผู้ให้บริการที่คุณเลือกเท่านั้น หรือไม่ไปไหนเลยในโหมดในเครื่อง
- **ไม่มีการป้อนตามคำบอกที่สูญหาย** เมื่อเครือข่ายหรือบริการออนไลน์ล้มเหลว โมเดลในเครื่องที่ติดตั้งไว้จะถอดเสียงจากการบันทึกเดียวกันบน Mac ของคุณ
- **ในภาษาของคุณ** การป้อนตามคำบอกใช้ได้หลายสิบภาษา และเมนู กล่องโต้ตอบ และการแจ้งเตือนมีให้ 35 ภาษา
- **คำของคุณ สะกดถูกต้อง** คำศัพท์ที่เป็นชื่อและศัพท์เทคนิคช่วยชี้นำ OpenAI, Groq, Whisper และการประมวลผลภายหลัง
- **ข้อความที่เรียบร้อยหากคุณต้องการ** การประมวลผลภายหลังซึ่งเป็นตัวเลือกเสริมจะตัดคำติดปาก แก้ไวยากรณ์ และเก็บไว้เฉพาะคำที่แก้แล้วเมื่อคุณพูดแก้ตัวเอง หรือจัดรูปแบบข้อความให้เข้ากับประเภทของแอปที่คุณป้อนตามคำบอกด้วย
- **คลิปบอร์ดยังเป็นของคุณ** Lowspeak วางผ่านคลิปบอร์ดและคืนสิ่งที่เคยอยู่ในนั้นกลับไปในอีกครู่ต่อมา การป้อนตามคำบอกสิบรายการล่าสุดยังอยู่ในเมนูเพื่อคัดลอกซ้ำได้
- **กด fn ค้างไว้ พูด แล้วปล่อย** ข้อความจะถูกพิมพ์ลงในแอปที่อยู่ด้านหน้า ตรงตำแหน่งเคอร์เซอร์ ไม่ว่าจะเป็นอีเมล แชท ตัวแก้ไข เทอร์มินัล หรือเบราว์เซอร์ ไม่ต้องสลับหน้าต่าง ไม่ต้องคลิกปุ่มใด
- **ล็อกไว้สำหรับข้อความยาว** กด Shift ขณะกด fn ค้างไว้ หรือกด fn สองครั้ง แล้วการบันทึกจะทำงานต่อไปโดยไม่ต้องกดปุ่มค้าง นานสูงสุดห้านาที กด fn หรือ Shift หนึ่งครั้งเพื่อสิ้นสุด
- **พูดต่อได้เลย** เริ่มการป้อนตามคำบอกครั้งถัดไปได้ขณะที่ครั้งก่อนยังถอดเสียงอยู่ ข้อความจะมาถึงตามลำดับที่คุณพูด

## ความต้องการของระบบ

- macOS 14 Sonoma ขึ้นไป Lowspeak พัฒนาและทดสอบบน macOS 27
- Mac ที่ใช้ Apple Silicon หรือโปรเซสเซอร์ Intel การถอดเสียงในเครื่องสร้างมาสำหรับ Apple Silicon ซึ่ง Whisper ทำงานบน GPU และ Parakeet ทำงานบน Neural Engine ส่วนบน Mac ที่ใช้ Intel ทั้งสองทำงานบนโปรเซสเซอร์และช้ากว่ามาก ดู [Mac ที่ใช้ Intel](#mac-ที่ใช้-intel)
- ประมาณ 17 MB สำหรับแอป บวก 75 MB ถึง 3 GB สำหรับแต่ละโมเดลในเครื่องที่คุณดาวน์โหลด
- สำหรับการถอดเสียงออนไลน์ ต้องมีคีย์ API จาก [OpenAI](https://platform.openai.com/api-keys) หรือ [Groq](https://console.groq.com/keys) โดย OpenAI เก็บค่าบริการตามปริมาณที่คุณถอดเสียง ส่วนแผนฟรีของ Groq ไม่มีค่าใช้จ่ายภายในขีดจำกัดรายวัน ซึ่งดูได้ในคอนโซลของ Groq การถอดเสียงในเครื่องไม่ต้องใช้บัญชี

## การติดตั้ง

**จากดิสก์อิมเมจ** ดาวน์โหลด [`Lowspeak.dmg`](https://github.com/sventmueller/lowspeak/releases/latest/download/Lowspeak.dmg) เปิดไฟล์ แล้วลาก Lowspeak ไปวางบนโฟลเดอร์แอปพลิเคชัน อิมเมจนี้ลงนามด้วย Developer ID และผ่านการรับรองโดย Apple จึงเปิดได้โดยไม่มีคำเตือน

**ผ่าน Homebrew** cask อยู่ใน tap ของตัวเอง:

```sh
brew install --cask sventmueller/tap/lowspeak
```

`brew uninstall --zap --cask lowspeak` จะลบการตั้งค่า โมเดล ไฟล์บันทึก และแคชของ Lowspeak ออกด้วย ส่วนคีย์ API ของคุณจะยังอยู่ในพวงกุญแจเข้าสู่ระบบ

**การอัปเดต** Lowspeak ที่ติดตั้งจากดิสก์อิมเมจหรือ Homebrew อัปเดตตัวเองผ่าน [Sparkle](https://sparkle-project.org) เมื่อเปิดครั้งที่สอง Lowspeak จะถามว่าอนุญาตให้ตรวจหารายการอัปเดตเองวันละครั้งหรือไม่ **ตรวจหารายการอัปเดต…** ในเมนูจะตรวจทันที ส่วน **ตรวจหารายการอัปเดตโดยอัตโนมัติ** และ **ดาวน์โหลดและติดตั้งรายการอัปเดตโดยอัตโนมัติ** ที่อยู่ด้านล่างใช้เปลี่ยนการตัดสินใจของคุณภายหลัง เมื่อการตรวจพบเวอร์ชั่นใหม่ขณะที่คุณทำงานอยู่ในแอปอื่น จะมีจุดปรากฏบนวงแหวนในแถบเมนู และ **ตรวจหารายการอัปเดต…** จะนำการอัปเดตขึ้นมาด้านหน้า Lowspeak จะติดตั้งการอัปเดตก็ต่อเมื่อมีลายเซ็นของนักพัฒนาเท่านั้น การตั้งค่า คีย์ และโมเดลของคุณจะยังอยู่ `brew upgrade --cask lowspeak` ก็อัปเดตสำเนาที่ติดตั้งจาก Homebrew ได้เช่นกัน เวอร์ชั่น 1.0.0 ไม่มีตัวอัปเดต ให้ติดตั้งเวอร์ชั่นที่ใหม่กว่าทับเพียงครั้งเดียวจาก[หน้ารุ่นเผยแพร่](https://github.com/sventmueller/lowspeak/releases) บิลด์ที่คุณสร้างเองก็ไม่มีตัวอัปเดตเช่นกัน

**จากซอร์สโค้ด** ดูสิ่งที่ต้องมีก่อนได้ที่ [การบิลด์และการติดตั้ง](../../../docs/development.md#build--deploy) จากนั้น:

```sh
make deploy
```

คำสั่งนี้จะบิลด์ Lowspeak แทนที่สำเนาในโฟลเดอร์แอปพลิเคชันของคุณ แล้วเปิดแอปขึ้นมา

**เปิดเมื่อเข้าสู่ระบบ** ในเมนูจะเริ่ม Lowspeak พร้อมกับ Mac ของคุณ ผ่านรายการเข้าสู่ระบบของ macOS เอง Lowspeak ทำงานได้ครั้งละหนึ่งสำเนาเท่านั้น สำเนาที่สองจะปิดตัวทันที

## เริ่มต้นใช้งาน

### สิทธิ์การเข้าถึง

เมื่อเปิดครั้งแรก Lowspeak จะขอสิทธิ์สามอย่าง:

- **การช่วยการเข้าถึง** (การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย › การช่วยการเข้าถึง ซึ่งใน macOS 27 รายการนี้ชื่อว่าการควบคุมอุปกรณ์และการเข้าถึงข้อมูล) Lowspeak ต้องใช้สิทธิ์นี้เพื่อตรวจจับปุ่ม fn และเพื่อวางด้วย ⌘V macOS จะเสนอให้เปิดรายการ ให้เปิดสวิตช์สำหรับ Lowspeak ข้อความของ Lowspeak เองจะเรียกชื่อรายการนี้ตามที่ macOS ของคุณแสดง

## การป้อนตามคำบอก

### กดค้างเพื่อพูด

กด fn ค้างไว้ พูด แล้วปล่อย ไอคอนการบันทึกจะปรากฏทันทีที่ไมโครโฟนส่งเสียงเข้ามา ให้เริ่มพูดตอนนั้น เพราะสิ่งที่คุณพูดก่อนหน้านั้นจะไม่ถูกบันทึก การปล่อย fn จะสิ้นสุดการบันทึก และข้อความจะตามมาในอีกครู่

การแตะ fn สั้นๆ จะไม่ทำอะไร fn จึงยังใช้ทำอย่างอื่นได้ตามเดิม การบันทึกที่ว่างเปล่าหรือยาวไม่ถึง 0.3 วินาทีจะถูกทิ้ง

### ล็อกด้วย Shift หรือกดสองครั้ง

สำหรับข้อความยาว ให้ล็อกการบันทึกเพื่อให้ทำงานต่อโดยไม่ต้องกดปุ่มค้าง มีสามวิธี:

- **Shift ขณะกด fn ค้างไว้** เริ่มด้วย fn ตามปกติแล้วกด Shift ระหว่างการบันทึก การบันทึกจะถูกล็อก และคุณปล่อย fn ได้ สิ่งที่พูดไปก่อนหน้าไม่หายไป การบันทึกเพียงดำเนินต่อไป
- **Shift แล้วตามด้วย fn** กด Shift ค้างไว้แล้วกด fn การบันทึกจะเริ่มในสถานะล็อก
- **fn สองครั้ง** แตะ fn สั้นๆ (ไม่ถึง 0.3 วินาที) แล้วกดอีกครั้งภายใน 0.4 วินาที การบันทึกเริ่มตั้งแต่การกดครั้งแรก

ไอคอนจะเปลี่ยนเป็นสี่เหลี่ยมมุมมน กด **fn** หรือ **Shift** หนึ่งครั้งเพื่อหยุด ข้อความจะตามมาตามปกติ หากตั้งค่าปุ่ม 🌐 ไว้ให้เปิดอิโมจิและสัญลักษณ์ ให้หยุดด้วย Shift เพราะการกด fn สั้นๆ จะเปิดหน้าต่างอิโมจิขึ้นมา

การบันทึกจะหยุดเองหลังผ่านไปสองนาทีขณะกด fn ค้างไว้ และหลังห้านาทีเมื่อล็อกไว้ จากนั้นจะถอดเสียงตามปกติ

### ข้อความไปลงที่ไหน

Lowspeak วางข้อความลงในแอปที่อยู่ด้านหน้าตอนที่คุณหยุดพูด ตรงตำแหน่งเคอร์เซอร์ ผ่านคลิปบอร์ดและ ⌘V โดยจะเก็บทุกอย่างที่อยู่ในคลิปบอร์ดก่อนหน้าไว้ และคืนกลับไปครึ่งวินาทีหลังจากที่แอปอ่านข้อความแล้ว หรือหลังจากสิบวินาทีหากแอปไม่อ่านเลย เว้นแต่จะมีแอปอื่นเปลี่ยนคลิปบอร์ดในระหว่างนั้น ข้อความจะถูกทำเครื่องหมายว่าเป็นข้อมูลชั่วคราว แอปประวัติคลิปบอร์ดที่เคารพเครื่องหมายนี้จึงไม่บันทึกข้อความดังกล่าว

คุณเริ่มการป้อนตามคำบอกครั้งถัดไปได้ขณะที่ครั้งก่อนยังถอดเสียงอยู่ ข้อความจะถูกวางตามลำดับที่คุณพูด และจะไม่ถูกวางขณะที่คุณกำลังบันทึกหรือกด Shift ค้างไว้ ข้อความที่วางจึงไม่โผล่กลางประโยคถัดไปของคุณ

หากไม่มีสิทธิ์การช่วยการเข้าถึง หรือเมื่อส่ง ⌘V จำลองไม่ได้ ข้อความจะยังอยู่ในคลิปบอร์ดและมีการแจ้งเตือนบอก ให้วางเองด้วย ⌘V

### การป้อนตามคำบอกล่าสุด

**การป้อนตามคำบอกล่าสุด** ในเมนูแสดงข้อความสิบรายการล่าสุด รายการใหม่สุดอยู่บนสุด แต่ละรายการย่อเหลือหนึ่งบรรทัด และเมื่อวางตัวชี้ไว้จะแสดงข้อความทั้งหมด คลิกเพื่อคัดลอกไปยังคลิปบอร์ด ใช้เมื่อข้อความไปลงผิดที่หรือคุณต้องใช้ซ้ำ รายการนี้อยู่ในหน่วยความจำเท่านั้นและจะว่างเปล่าหลังจากออกจาก Lowspeak

โมเดลในเครื่องใช้พื้นที่ดิสก์เท่ากับขนาดดาวน์โหลด และขณะที่เลือกใช้อยู่ก็ใช้หน่วยความจำในปริมาณใกล้เคียงกัน Lowspeak จะโหลดโมเดลค้างไว้เพื่อให้การป้อนตามคำบอกเริ่มได้ทันที บน Mac ที่มีหน่วยความจำ 8 GB ควรเลือก Parakeet Ultra หรือโมเดลออนไลน์แทนโมเดล Whisper ขนาดใหญ่

### ออนไลน์: OpenAI และ Groq

| โมเดล | ผู้ให้บริการ | หมายเหตุ |
|---|---|---|
| **GPT Transcribe** (ค่าเริ่มต้น) | OpenAI | แม่นยำที่สุด รับคำศัพท์ของคุณเป็นคีย์เวิร์ด |
| **Whisper** | OpenAI | โมเดล Whisper ดั้งเดิม |
| **Whisper Large V3** | Groq | เร็วมาก |
| **Whisper Large V3 Turbo** | Groq | เร็วที่สุดในแบบออนไลน์ |

เสียงที่บันทึกจะถูกบีบอัดเป็น AAC ก่อนอัปโหลด ประมาณ 6 KB ต่อเสียงพูดหนึ่งวินาที การป้อนตามคำบอกจึงใช้ได้แม้บนการเชื่อมต่อที่ช้า ขณะที่คุณกด fn ค้างไว้ Lowspeak จะเปิดการเชื่อมต่อกับผู้ให้บริการไว้ก่อน การอัปโหลดจึงเริ่มทันทีที่คุณปล่อยปุ่ม

### บน Mac ของคุณ: Whisper และ Parakeet

| โมเดล | ขนาด | ทำงานบน | ภาษา |
|---|---|---|---|
| **Parakeet Ultra** | ~630 MB | Neural Engine | 25 ภาษายุโรป |
| **Parakeet v2** | ~600 MB | Neural Engine | อังกฤษ |
| **Whisper Large v3 Turbo** | ~1.6 GB | GPU (Metal) | ประมาณ 99 |
| **Whisper Large v3** | ~3 GB | GPU (Metal) | ประมาณ 99 |
| **Whisper Medium** | ~1.5 GB | GPU (Metal) | ประมาณ 99 |
| **Whisper Small** | ~470 MB | GPU (Metal) | ประมาณ 99 |
| **Whisper Base** | ~150 MB | GPU (Metal) | ประมาณ 99 |
| **Whisper Tiny** | ~75 MB | GPU (Metal) | ประมาณ 99 |

**จัดการโมเดล** ใช้ดาวน์โหลดและลบโมเดล ระหว่างดาวน์โหลด แถบเมนูจะแสดงความคืบหน้า และการออกจาก Lowspeak จะยกเลิกการดาวน์โหลด การใช้โมเดลครั้งแรกสุดจะเตรียมโมเดลให้เหมาะกับ Mac ของคุณ ประมาณ 10 วินาทีสำหรับ Parakeet Ultra และนานสุด 30 วินาทีสำหรับ Whisper หลังจากนั้นจะโหลดเสร็จในเสี้ยววินาที หากโมเดลที่คุณเลือกถูกลบ Lowspeak จะสลับไปใช้โมเดลอื่นที่ติดตั้งไว้

**Parakeet** เป็นตัวเลือกที่เร็วที่สุด ถอดเสียงพูด 40 วินาทีได้ในราว 0.3 วินาที Lowspeak ใช้โมเดลและการถอดรหัสแบบเดียวกับ [FluidAudio](https://github.com/FluidInference/FluidAudio) และเก็บโมเดลไว้ในโฟลเดอร์ของ FluidAudio (`~/Library/Application Support/FluidAudio/Models`) แอปที่สร้างบน FluidAudio จึงใช้โมเดลร่วมกันได้ การบันทึกที่ยาวกว่า 15 วินาทีจะถอดเสียงเป็นช่วงที่ซ้อนทับกัน แล้วนำมาต่อกันโดยไม่ทำให้คำตรงรอยต่อหายไป **Whisper** เข้าใจภาษาได้มากกว่าและอ่านคำศัพท์ของคุณ โมเดลขนาดใหญ่แม่นยำที่สุด ส่วนโมเดลขนาดเล็กด้อยกว่ามากในภาษาอื่นนอกจากภาษาอังกฤษ โมเดล Whisper เก็บไว้ใน `~/Library/Application Support/Lowspeak/Models`

### เมื่อบริการออนไลน์ล้มเหลว

หากการถอดเสียงออนไลน์ล้มเหลว เพราะเครือข่ายใช้ไม่ได้ ผู้ให้บริการมีปัญหา หรือคีย์ไม่ถูกต้อง โมเดลในเครื่องที่ติดตั้งไว้จะถอดเสียงจากการบันทึกเดียวกัน ได้แก่โมเดลที่เลือกไว้ใต้ **ในเครื่อง** หากไม่มีจะใช้ Parakeet Ultra ตามด้วย Whisper Large v3 Turbo, Large v3 และโมเดล Whisper ที่เล็กกว่า โดย Parakeet v2 อยู่ลำดับสุดท้าย การแจ้งเตือนจะบอกคุณหนึ่งครั้ง และจะแจ้งอีกก็ต่อเมื่อมีการป้อนตามคำบอกแบบออนไลน์ที่สำเร็จคั่นกลางแล้วเท่านั้น

เมื่อมีโมเดลในเครื่องเป็นตัวสำรอง Lowspeak จะให้เวลาคำขอออนไลน์ 20 วินาที หากไม่มี จะลองสามครั้ง ครั้งละไม่เกินหนึ่งนาที ในโหมดออนไลน์ Lowspeak จะเตรียมโมเดล Parakeet สำรองหนึ่งครั้งตอนเปิดแอป การสลับไปใช้ตัวสำรองครั้งแรกจึงไม่ต้องรอ

### การเตรียมเสียงที่บันทึก

Lowspeak บันทึกเสียงที่อัตราสุ่มตัวอย่างของไมโครโฟนเอง และแปลงเป็น 16 kHz ที่โมเดลต้องการเมื่อคุณหยุด ก่อนถอดเสียง Lowspeak จะตัดเสียงหึ่งความถี่ต่ำที่ต่ำกว่า 80 Hz ตัดช่วงเงียบที่ต้นและท้าย และปรับระดับเสียงให้สม่ำเสมอ ผู้พูดเสียงเบาและเสียงดังจึงได้ผลเหมือนกัน การบันทึกที่ไม่มีเสียงพูดจะไม่ถูกส่งไปเลย ในโหมดในเครื่อง Parakeet จะได้รับเสียงที่บันทึกโดยไม่ผ่านการปรับแต่งก่อน และจะได้รับเสียงที่เตรียมแล้วก็ต่อเมื่อครั้งแรกไม่ได้ข้อความ

### ภาษาของแต่ละโมเดล

ภาษาที่เลือกใต้ **ภาษา** จะส่งต่อให้โมเดลออนไลน์และ Whisper หากเลือก **ตรวจหาอัตโนมัติ** โมเดลจะระบุภาษาเอง

| โมเดล | ภาษาที่คุณป้อนตามคำบอกได้ |
|---|---|
| GPT Transcribe, Whisper (OpenAI, Groq, บน Mac ของคุณ) | ประมาณ 99 ภาษา รวมทั้ง 35 ภาษาของเมนูทั้งหมด |
| Parakeet Ultra | บัลแกเรีย โครเอเชีย เช็ก เดนมาร์ก ดัตช์ อังกฤษ เอสโตเนีย ฟินแลนด์ ฝรั่งเศส เยอรมัน กรีก ฮังการี อิตาลี ลัตเวีย ลิทัวเนีย มอลตา โปแลนด์ โปรตุเกส โรมาเนีย รัสเซีย สโลวัก สโลวีเนีย สเปน สวีเดน ยูเครน |
| Parakeet v2 | อังกฤษ |

Parakeet ตรวจหาภาษาเองและไม่สนใจตัวเลือกในเมนู **จีน (ตัวเต็ม)** สั่งให้ GPT Transcribe เขียนเป็นอักษรจีนตัวเต็ม ส่วน Whisper เขียนภาษาจีนเป็นอักษรแบบใดแบบหนึ่ง และเขียนภาษาโปรตุเกสโดยไม่คำนึงถึงรูปแบบภาษา

### Mac ที่ใช้ Intel

Lowspeak เป็นแอป Universal และทำงานบน Mac ที่ใช้ Intel ซึ่งมี macOS 14 ได้เช่นกัน ทุกอย่างที่เป็นออนไลน์ทำงานเหมือนเดิม แต่บนเครื่องเหล่านี้ โมเดลในเครื่องจะไม่มีฮาร์ดแวร์ที่ออกแบบมาให้ใช้ Whisper ทำงานบนโปรเซสเซอร์แทน GPU และ Parakeet ทำงานบนโปรเซสเซอร์แทน Neural Engine ทั้งสองใช้งานได้ แต่ใช้เวลานานกว่าบน Apple Silicon หลายเท่า และโมเดล Whisper ขนาดใหญ่ช้าเกินกว่าจะใช้ป้อนตามคำบอก บน Mac ที่ใช้ Intel ให้ถอดเสียงแบบออนไลน์ และเก็บ Whisper Small หรือ Parakeet Ultra ไว้เป็น[ตัวสำรอง](#เมื่อบริการออนไลน์ล้มเหลว)

## คำศัพท์

**คำศัพท์…** รับชื่อและศัพท์ที่ Lowspeak ควรสะกดให้ตรง คั่นด้วยเครื่องหมายจุลภาค เช่น ชื่อผลิตภัณฑ์ ชื่อเพื่อนร่วมงาน ศัพท์เทคนิค ได้สูงสุด 100 คำ คำละไม่เกิน 60 อักขระ โดย `<` และ `>` จะถูกลบออก

- **GPT Transcribe** รับคำเหล่านี้เป็นคีย์เวิร์ด
- **Whisper** (OpenAI, Groq และบน Mac ของคุณ) อ่านคำเหล่านี้เป็นคำใบ้ก่อนการบันทึก สูงสุด 500 อักขระ
- **การประมวลผลภายหลัง** ได้รับคำสั่งให้สะกดตรงตามที่เขียนไว้ทุกตัวอักษร
- **Parakeet** ไม่ใช้คำเหล่านี้

## การประมวลผลภายหลัง

หลังถอดเสียง โมเดลภาษาสามารถปรับแต่งข้อความได้ เลือกใต้ **การประมวลผลภายหลัง**:

- **ปิด** (ค่าเริ่มต้น) — ข้อความตามที่ถอดเสียงได้
- **ขัดเกลา** — ตัดคำติดปาก เช่น “เอ่อ” “แบบว่า” หรือ “คือ” แก้ไวยากรณ์และเครื่องหมายวรรคตอน และเก็บไว้เฉพาะคำที่แก้แล้วเมื่อคุณพูดแก้ตัวเอง โดยไม่เพิ่มอะไรและไม่เปลี่ยนความหมาย
- **จัดรูปแบบ** — เหมือนขัดเกลา และปรับข้อความให้เข้ากับแอปที่คุณป้อนตามคำบอก: ศัพท์แบบโค้ดในตัวแก้ไขโค้ด บรรทัดคำสั่งในเทอร์มินัล น้ำเสียงเป็นกันเองในแอปแชท และน้ำเสียงเป็นทางการในอีเมล

การประมวลผลภายหลังใช้ Groq (`openai/gpt-oss-120b`) หากคุณมีคีย์ Groq มิฉะนั้นจะใช้ OpenAI (`gpt-4o-mini`) แม้เมื่อคุณถอดเสียงในเครื่อง หากเลือกภาษาไว้ใต้ **ภาษา** จะคงภาษานั้นไว้ หากใช้เวลานานกว่าแปดวินาที ล้มเหลว หรือส่งคำตอบที่ถูกตัดกลางคันหรือยาวกว่าสิ่งที่คุณพูดไปมาก Lowspeak จะวางข้อความที่ยังไม่ผ่านการประมวลผล หากผู้ให้บริการปฏิเสธคำขอหรือยังไม่ได้ตั้งค่าคีย์ จะมีการแจ้งเตือนบอกหนึ่งครั้ง

## ไมโครโฟน

ใต้ **ไมโครโฟน** ให้เลือกไมโครโฟนที่ต้องการหรือ **ค่าเริ่มต้นของระบบ** Lowspeak จะจำอุปกรณ์ไว้ ขณะที่อุปกรณ์ไม่ได้เชื่อมต่อ เมนูจะแสดงเป็น **(ไม่ได้เชื่อมต่อ)** และ Lowspeak จะบันทึกด้วยค่าเริ่มต้นของระบบ

ไมโครโฟนจะเปิดเฉพาะขณะที่คุณป้อนตามคำบอก การเตรียมไมโครโฟนให้พร้อมใช้เวลาประมาณ 0.07 วินาทีกับไมโครโฟนในตัว ประมาณครึ่งวินาทีกับ Studio Display และหนึ่งถึงสองวินาทีกับ AirPods ซึ่งต้องสลับไปใช้โหมดชุดหูฟังก่อน ไอคอนการบันทึกจะปรากฏเมื่อเสียงเข้ามา **เล่นเสียงเมื่อพร้อม** จะเพิ่มเสียงสั้นๆ ณ ตอนนั้น ตัวเลือกนี้ปิดไว้เป็นค่าเริ่มต้น เพราะลำโพงบางรุ่นจะเล่นเสียงนั้นช้าไปครึ่งวินาที

หากไมโครโฟนส่งมาแต่ความเงียบเป็นเวลาห้าวินาที อย่างที่เกิดกับ AirPods เมื่ออุปกรณ์อื่นใช้ไมโครโฟนอยู่ Lowspeak จะแจ้งให้คุณทราบ

## คีย์ API

**ตั้งค่าคีย์ API…** จะขอคีย์และรู้จักผู้ให้บริการจากส่วนขึ้นต้น: `sk-` สำหรับ OpenAI, `gsk_` สำหรับ Groq คีย์ในรูปแบบอื่นจะถูกปฏิเสธพร้อมคำอธิบาย ป้อนหนึ่งคีย์ต่อผู้ให้บริการ เมื่อมีคีย์ของทั้งสอง โมเดลออนไลน์ทั้งหมดจะพร้อมใช้ **อัปเดตคีย์ API…** ใช้แทนที่คีย์ หรือใช้ลบคีย์ด้วย **เอาคีย์ทั้งหมดออก**

คีย์เก็บอยู่ในพวงกุญแจเข้าสู่ระบบของคุณภายใต้ชื่อ `com.lowspeak.app` ไฟล์คีย์ของเวอร์ชั่นก่อนหน้า (`~/Library/Application Support/Lowspeak/.api-key`) จะถูกย้ายไปไว้ในพวงกุญแจเมื่อเปิดครั้งถัดไป และจะถูกลบเมื่ออ่านคีย์ทุกตัวกลับจากพวงกุญแจได้แล้ว

## การแจ้งเตือน

Lowspeak ทำงานอยู่เบื้องหลัง จึงรายงานปัญหาเป็นการแจ้งเตือน:

| การแจ้งเตือน | สิ่งที่เกิดขึ้น |
|---|---|
| **บันทึกเสียงไม่สำเร็จ** | ไม่มีสิทธิ์เข้าถึงไมโครโฟน ไม่มีไมโครโฟนเชื่อมต่ออยู่ หรือเริ่มไมโครโฟนไม่ได้ |
| **ไมโครโฟนไม่มีเสียง** | เงียบไปห้าวินาที ดู [ไมโครโฟน](#ไมโครโฟน) |
| **ต้องได้รับอนุญาตการช่วยการเข้าถึง** | ข้อความอยู่ในคลิปบอร์ด อนุญาตการช่วยการเข้าถึงเพื่อให้วางได้โดยอัตโนมัติ |
| **วางไม่สำเร็จ** | ข้อความอยู่ในคลิปบอร์ด วางด้วย ⌘V |
| **ถอดเสียงไม่สำเร็จ** | พร้อมเหตุผล: ไม่มีคีย์ คีย์ถูกปฏิเสธ เกินขีดจำกัดจำนวนคำขอ ข้อผิดพลาดของเซิร์ฟเวอร์หรือเครือข่าย หรือไม่มีโมเดลในเครื่อง |
| **ถอดเสียงบน Mac เครื่องนี้แล้ว** | บริการออนไลน์ล้มเหลวและโมเดลในเครื่องทำงานแทน |
| **ประมวลผลภายหลังไม่สำเร็จ** | ผู้ให้บริการปฏิเสธการประมวลผลภายหลังหรือยังไม่ได้ตั้งค่าคีย์ ข้อความถูกวางโดยไม่ผ่านการประมวลผลภายหลัง |
| **ไม่มีคีย์ API** | คุณเลือกโมเดลออนไลน์โดยไม่มีคีย์ของผู้ให้บริการนั้น |
| **ดาวน์โหลดไม่สำเร็จ**, **ลบไม่สำเร็จ**, **ไม่สามารถลบได้** | การจัดการโมเดลในเครื่องไม่สำเร็จ หรือยังมีการดำเนินการอื่นทำงานอยู่ |
| **ข้อผิดพลาดของรายการเข้าสู่ระบบ**, **ข้อผิดพลาดของคีย์ API** | macOS หรือพวงกุญแจปฏิเสธการเปลี่ยนแปลง |

การแจ้งเตือนไม่มีข้อความที่คุณป้อนตามคำบอกเลย บริการออนไลน์ที่ล้มเหลวและผู้ให้บริการประมวลผลภายหลังที่ปฏิเสธคำขอจะถูกรายงานหนึ่งครั้ง ไม่ใช่หลังการป้อนตามคำบอกทุกครั้ง จนกว่าจะกลับมาทำงานได้

## หน้าตาและการช่วยการเข้าถึง

- **ไอคอนในแถบเมนู** เป็นภาพแม่แบบที่เปลี่ยนตามแถบเมนูแบบสว่าง มืด หรือแบบมีสี
- **VoiceOver** อ่านไอคอนว่า “Lowspeak” และเมนู หน้าต่างเตือน และการแจ้งเตือนเป็นตัวควบคุมมาตรฐานของ macOS
- **ไม่ต้องกดปุ่มค้าง** ล็อกการบันทึกด้วย Shift หรือกด fn สองครั้ง แล้วการกดครั้งถัดไปจะสิ้นสุดการบันทึก
- **ข้อมูลอ้างอิงด่วน** เป็นหน้าต่างธรรมดาที่มีป้ายกำกับและปุ่ม ใช้งานได้จากแป้นพิมพ์ และ Esc จะปิดหน้าต่างนี้

ข้อบกพร่องที่ทราบแสดงไว้ใน [ACCESSIBILITY.md](../../../ACCESSIBILITY.md): VoiceOver ไม่ประกาศเมื่อการบันทึกเริ่ม และ Lowspeak ยังไม่ได้ตรวจสอบกับ VoiceOver หรือการควบคุมสวิตช์

## ภาษา

เมนู กล่องโต้ตอบ และการแจ้งเตือนแปลเป็น 35 ภาษา:

อาหรับ คาตาลัน จีน (ตัวย่อ) จีน (ตัวเต็ม) โครเอเชีย เช็ก เดนมาร์ก ดัตช์ อังกฤษ ฟินแลนด์ ฝรั่งเศส เยอรมัน กรีก ฮีบรู ฮินดี ฮังการี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี มาเลย์ นอร์เวย์ โปแลนด์ โปรตุเกส (บราซิล) โปรตุเกส (โปรตุเกส) โรมาเนีย รัสเซีย สโลวัก สโลวีเนีย สเปน สวีเดน ไทย ตุรกี ยูเครน และเวียดนาม

ภาษาที่คุณเลือกใต้ **ภาษา** จะเป็นภาษาของเมนูด้วย หากเลือก **ตรวจหาอัตโนมัติ** เมนูจะทำตามลำดับภาษาใน **การตั้งค่าระบบ › ทั่วไป › ภาษาและภูมิภาค** และใช้ภาษาอังกฤษหากไม่มีคำแปล คำในเมนูเป็นไปตามคำแปลของ Apple เอง Lowspeak จึงอ่านเหมือนส่วนอื่นของ Mac นอกจากภาษาอังกฤษแล้ว คำแปลทั้งหมดแปลด้วยเครื่องและยังไม่ได้รับการตรวจทานโดยเจ้าของภาษา ยินดีรับการแก้ไขในรูปแบบ [issue](https://github.com/sventmueller/lowspeak/issues/new/choose)

## ปุ่มและท่าทาง

| การทำงาน | ปุ่ม |
|---|---|
| ป้อนตามคำบอกขณะกดค้าง | กด fn ค้างไว้ |
| ล็อกการบันทึกที่กำลังทำงาน | Shift ขณะกด fn ค้างไว้ |
| เริ่มการบันทึกแบบล็อก | Shift+fn หรือกด fn สองครั้งเร็วๆ |
| สิ้นสุดการบันทึกแบบล็อก | fn หรือ Shift |
| ออกจาก Lowspeak (ขณะเมนูเปิด) | ⌘Q |
| ปิดข้อมูลอ้างอิงด่วน | Esc |

Lowspeak กันไม่ให้การกด fn ที่ตัวเองใช้ส่งต่อไปยังแอปอื่น ส่วน Shift ส่งผ่านไปตามปกติ

## ความเป็นส่วนตัวและความปลอดภัย

Lowspeak ได้ยินสิ่งที่คุณพูดขณะกด fn ค้างไว้ พิมพ์ลงในแอปใดก็ได้ และเก็บคีย์ API ของคุณ จึงทำสิ่งต่างๆ กับข้อมูลเหล่านี้ให้น้อยที่สุดเท่าที่ทำได้

- **เสียงของคุณไปที่เดียว** ในโหมดออนไลน์ เสียงที่บันทึกจะถูกบีบอัดแล้วส่งไปยังผู้ให้บริการที่คุณเลือก คือ OpenAI หรือ Groq พร้อมกับคำศัพท์ของคุณ ในโหมดในเครื่อง ไม่มีอะไรออกจาก Mac ของคุณ เมื่อคำขอออนไลน์ล้มเหลว โมเดลในเครื่องจะถอดเสียงจากการบันทึกเดียวกันบน Mac ของคุณ
- **การประมวลผลภายหลัง** หากคุณเปิดใช้ จะส่งข้อความที่ถอดเสียงแล้วและคำศัพท์ของคุณไปยัง Groq หรือ OpenAI ในโหมดจัดรูปแบบจะส่งประเภทของแอปที่คุณป้อนตามคำบอกไปด้วย (ตัวแก้ไขโค้ด เทอร์มินัล แชท หรืออีเมล) แต่ไม่ส่งชื่อแอป
- **ไม่มีการเก็บข้อมูลการใช้งาน ไม่มีบัญชี** นอกจากการถอดเสียงและการประมวลผลภายหลัง Lowspeak จะออนไลน์เพียงเพื่อเปิดการเชื่อมต่อกับผู้ให้บริการของคุณขณะกด fn ค้างไว้ ในโหมดออนไลน์หรือเมื่อเปิดการประมวลผลภายหลัง เพื่อดาวน์โหลดโมเดลเมื่อคุณสั่ง จาก Hugging Face ผ่าน HTTPS ในเวอร์ชั่นที่กำหนดตายตัว และตรวจทุกไฟล์กับเช็คซัมของไฟล์นั้น และเพื่อตรวจหาเวอร์ชั่นใหม่บน GitHub วันละครั้งหากคุณอนุญาต คำขอนั้นมีเพียงเวอร์ชั่นของ Lowspeak เท่านั้น **วิธีใช้ › รายงานปัญหา…** จะเปิดแบบฟอร์มบน GitHub ในเบราว์เซอร์ ที่อยู่ของแบบฟอร์มมีเวอร์ชั่นของ Lowspeak และเวอร์ชั่นของ macOS ไม่มีสิ่งใดที่คุณป้อนตามคำบอก
- **คีย์ API** อยู่ในพวงกุญแจเข้าสู่ระบบของคุณ คีย์จะถูกส่งไปยังผู้ให้บริการของคีย์นั้นเท่านั้น และถูกลบออกจากข้อความแสดงข้อผิดพลาดก่อนจะเขียนสิ่งใดลงในบันทึก
- **ไม่เก็บข้อความที่ป้อนตามคำบอก** การป้อนตามคำบอกสิบรายการล่าสุดอยู่ในหน่วยความจำสำหรับ **การป้อนตามคำบอกล่าสุด** และหายไปเมื่อออกจาก Lowspeak ไฟล์บันทึกจะบันทึกความยาวและเวลา แต่ไม่บันทึกข้อความ
- **คลิปบอร์ด** จะถูกเก็บไว้ก่อนวาง และคืนค่าเมื่อแอปอ่านข้อความแล้ว เว้นแต่จะมีแอปอื่นเปลี่ยนคลิปบอร์ดในระหว่างนั้น ข้อความที่ป้อนตามคำบอกจะถูกทำเครื่องหมายว่าเป็นข้อมูลชั่วคราว แอปประวัติคลิปบอร์ดที่เคารพเครื่องหมายนี้จึงข้ามข้อความดังกล่าวไป
- **การลงนามโค้ด** พร้อม Hardened Runtime แอปขอสิทธิ์เฉพาะไมโครโฟน การช่วยการเข้าถึง การแจ้งเตือน และเครือข่าย การอัปเดตต้องมีลายเซ็นของนักพัฒนา มิฉะนั้น Sparkle จะปฏิเสธ

หากต้องการรายงานช่องโหว่ โปรดทำตาม[นโยบายความปลอดภัย](../../../SECURITY.md)

## ความเร็ว

วัดบน Apple Silicon:

- **Parakeet Ultra** ถอดเสียงพูด 40 วินาทีได้ในราว 0.3 วินาที
- **ออนไลน์:** คำขอแรกหลังจากหยุดไปช่วงหนึ่งใช้เวลาประมาณ 0.4 วินาทีที่ Groq เพราะ Lowspeak เปิดการเชื่อมต่อไว้ตั้งแต่คุณยังพูดอยู่ คำขอถัดไปจะใช้การเชื่อมต่อนั้นซ้ำ ผ่าน HTTP/3 หากผู้ให้บริการรองรับ
- **ขนาดการอัปโหลด:** ประมาณ 6 KB ต่อเสียงพูดหนึ่งวินาที เป็น AAC ที่ 48 kbit/s
- **การเตรียมไมโครโฟน:** ประมาณ 0.07 วินาทีกับไมโครโฟนในตัว ครึ่งวินาทีกับ Studio Display และหนึ่งถึงสองวินาทีกับ AirPods

## ข้อจำกัดที่ทราบ

- **โมเดลในเครื่องบน Mac ที่ใช้ Intel** ทำงานบนโปรเซสเซอร์และช้ากว่ามาก การถอดเสียงออนไลน์จึงเป็นตัวเลือกที่ดีกว่าบนเครื่องเหล่านั้น
- **สิ่งที่คุณพูดก่อนไมโครโฟนพร้อมจะหายไป** รอให้ไอคอนการบันทึกปรากฏก่อน โดยเฉพาะกับ AirPods
- **ปุ่ม fn อาจถูกโปรแกรมอื่นแย่งไป** เมื่อการตั้งค่าปุ่ม 🌐 ของ macOS, Warp หรือการป้อนตามคำบอกของ macOS จับ fn ไปก่อน Lowspeak จะมองไม่เห็นปุ่มนี้ ดู [การแก้ปัญหา](#การแก้ปัญหา)
- **Parakeet** ไม่สนใจคำศัพท์และตัวเลือกภาษา และรู้จักเฉพาะภาษายุโรป
- **ชุดอักษรและรูปแบบภาษา:** มีเพียง GPT Transcribe ที่สั่งให้เขียนภาษาจีนตัวเต็มได้ ไม่มีโมเดลใดที่สั่งให้เขียนภาษาโปรตุเกสแบบยุโรปแทนแบบบราซิลได้
- **ขีดจำกัดเวลา:** สองนาทีขณะกด fn ค้างไว้ ห้านาทีเมื่อล็อก
- **โหมดไมค์:** ศูนย์ควบคุมเสนอแยกเสียงและสเปกตรัมกว้างให้ Lowspeak และรายงานว่าเปิดใช้งานอยู่ แต่ Lowspeak บันทึกเสียงโดยไม่ผ่านการประมวลผลเสียงพูด ตัวเลือกนี้จึงไม่มีผล
- **การป้อนตามคำบอกล่าสุด** อยู่ในหน่วยความจำเท่านั้นและหายไปหลังจากออกจากแอป
- **โดยการออกแบบ:** ไม่มีหน้าต่างการตั้งค่า ไม่มีไอคอนใน Dock และไม่อยู่ใน App Store

## การแก้ปัญหา

**ไม่มีอะไรเกิดขึ้นเมื่อฉันกด fn ค้างไว้** ตรวจสอบสามอย่าง: Lowspeak ได้รับอนุญาตแล้วใน **การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย › การช่วยการเข้าถึง** (ใน macOS 27: **การควบคุมอุปกรณ์และการเข้าถึงข้อมูล**) ตั้ง **การตั้งค่าระบบ › แป้นพิมพ์ › กดปุ่ม 🌐 เพื่อ** เป็น **ไม่ดำเนินการใดๆ** แล้ว และไม่มีแอปอื่นจับ fn ไว้ Warp ทำเช่นนั้นเป็นค่าเริ่มต้น ปิดได้ด้วย `defaults write dev.warp.Warp-Stable VoiceInputToggleKey '""'` แล้วเปิด Warp ใหม่ การป้อนตามคำบอกของ macOS ก็ตั้งให้เริ่มด้วย fn ได้เช่นกัน

**หลังอัปเดต Lowspeak ไม่ตอบสนองต่อ fn อีกต่อไป** macOS ผูกสิทธิ์การช่วยการเข้าถึงไว้กับลายเซ็นของแอป หากลายเซ็นเปลี่ยน เช่น จากบิลด์ที่คุณสร้างเองเป็นแอปที่ดาวน์โหลดมา ให้เอา Lowspeak ออกจากรายการการช่วยการเข้าถึง (ใน macOS 27: การควบคุมอุปกรณ์และการเข้าถึงข้อมูล) แล้วเพิ่มกลับเข้าไปใหม่

**คำแรกๆ หายไป** เริ่มพูดเมื่อไอคอนการบันทึกปรากฏแล้ว กับ AirPods ไมโครโฟนต้องใช้เวลาหนึ่งถึงสองวินาที ส่วนไมโครโฟนในตัวหรือ USB ที่เลือกใต้ **ไมโครโฟน** จะพร้อมแทบทันที

**“ไมโครโฟนไม่มีเสียง”** ไมโครโฟนไม่ส่งเสียงมาเลยเป็นเวลาห้าวินาที กับ AirPods อุปกรณ์อื่นอาจกำลังใช้ไมโครโฟนของ AirPods อยู่ ให้สลับไปใช้ไมโครโฟนในตัวหรือเชื่อมต่อ AirPods ใหม่ การปิดฝา MacBook ก็ทำให้ไมโครโฟนในตัวไม่มีเสียงเช่นกัน

**การป้อนตามคำบอกออกมาว่างเปล่า** ระดับเสียงสัญญาณเข้าอาจต่ำเกินไป แอปอย่าง Teams, Zoom หรือ Meet จะเปลี่ยนค่านี้ระหว่างการโทร และ macOS เก็บค่านี้แยกตามอุปกรณ์ เพิ่มระดับได้ใน **การตั้งค่าระบบ › เสียง › สัญญาณเข้า**

**ข้อความไปลงผิดที่** **การป้อนตามคำบอกล่าสุด** ในเมนูจะคัดลอกข้อความไปยังคลิปบอร์ดอีกครั้ง

**“ไม่มีคีย์ API”** เลือก **ตั้งค่าคีย์ API…** ในเมนู หรือสลับไปใช้โมเดลในเครื่อง

**การถอดเสียงในเครื่องครั้งแรกใช้เวลานาน** แต่ละโมเดลจะถูกเตรียมให้เหมาะกับ Mac ของคุณในการใช้งานครั้งแรก หลังจากนั้นจะโหลดเสร็จในเสี้ยววินาที

**Lowspeak ปิดตัวทันทีหลังเปิด** มี Lowspeak อีกสำเนาหนึ่งทำงานอยู่แล้ว ให้ออกจากสำเนานั้นก่อน

**ไม่มีการแจ้งเตือนปรากฏ** อนุญาตได้ใน **การตั้งค่าระบบ › การแจ้งเตือน › Lowspeak**

**ปัญหาอื่นๆ** ไฟล์บันทึกใน `~/Library/Application Support/Lowspeak/` (`appstate.log`, `audio.log`, `hotkey.log`, `crash.log`) อธิบายสิ่งที่เกิดขึ้น โดยไม่มีข้อความที่คุณป้อนตามคำบอก แนบบรรทัดที่เกี่ยวข้องไปกับ[รายงานปัญหา](https://github.com/sventmueller/lowspeak/issues/new/choose)
