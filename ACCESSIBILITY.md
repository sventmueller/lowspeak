# Accessibility

Lowspeak lives in the menu bar and uses the standard macOS menu, alerts and notifications, so VoiceOver reads them as
in any Mac app. The menu bar icon is named "Lowspeak" for VoiceOver, and the Quick Reference window consists of plain
labels and a button.

Dictation does not require holding a key: a double press of fn, or Shift+fn, records hands-free until the next press
of fn or Shift.

Known limits: whether recording is running shows in the icon's shape and, if turned on, in a sound; VoiceOver does not
announce it. Nor does it announce the dot that marks a waiting update; **Check for Updates…** in the menu then carries a
badge as well. The menu, the Quick Reference and the hands-free gestures have not yet been checked with VoiceOver or
Switch Control.

If something in Lowspeak is a barrier for you, [report it as a problem](https://github.com/sventmueller/lowspeak/issues/new/choose).
